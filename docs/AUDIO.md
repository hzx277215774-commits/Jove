# Background music / 背景音乐

当前音乐：**Adam Young — Wheels Down**。

文件由作者在本次对话中提供，从本地文件原样复制至 `public/audio/mang-theme.mp3`，没有重新编码或下载替代版本。浏览器验证音频约 218 秒。

配置位于 `data/config.ts`：默认音量 0.3，上限 0.4；用户点击进入后渐入、循环播放。切换语言和站内页面不重建播放器；用户暂停后保留关闭偏好。刷新时等待下一次合法点击再播放。

更换文件后需重新构建和发布。删除文件时，下一次构建自动降级为静音；网络或解码失败不阻止进入网站。

运行 `node scripts/qa-audio.cjs` 可以检查实际文件解码、点击播放、渐入、语言／路由切换连续性、音量上限与持久化。运行前先构建并启动本地静态预览。

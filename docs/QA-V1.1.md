# V1.1 验证记录

## 自动检查

- `pnpm run build`：TypeScript 检查和生产静态导出通过，10 个静态页面。
- `scripts/qa-v11.cjs`：375、390、768、1024、1440、1920 六档宽度，首页与七个档案页共 48 组页面检查。
- 每个尺寸检查启动页、进入按钮、标题、图片解码、页面宽度与公开文案；未发现页面横向溢出、损坏图片、浏览器运行错误或资源 HTTP 错误。
- 会话内刷新与导航跳过启动页、新会话显示启动页、深层档案直达、Logo 返回正式首页、禁用 Storage 兜底、减少动态效果。
- 地图分类、桌面悬停、手机点击档案、缩放重置；人物与画廊弹窗、翻页、Escape 和焦点返回；移动导航 Tab 循环和 Escape。
- `scripts/qa-content.cjs`：CANON 四种状态、八页独立 SEO 标题、OG 和描述、导出包不含撤下的地名和开发备注、18 张作者原图保留、无测试音轨、生成图退出公开目录。

## 音频检查

使用临时本地合成的静音 PCM 测试文件进行音频可用构建；测试后移除并重新构建正式静音版本。没有下载或发布任何测试音乐。

`qa-audio.cjs` 验证：点击前不请求音频、不自动播放；点击后渐入至 0.3；loop；SPA 路由间使用同一 audio 且播放时间继续；最大音量 0.4；暂停、音量和偏好持久化；用户关闭后进入不强制播放；刷新等待合法点击；播放策略拒绝及损坏文件均不阻断页面。

复现音频检查需要临时测试文件令构建的音频可用标记为 true，并在 `output/v11-qa/test-audio.wav` 准备本地测试音频。该测试仅用于开发；不得覆盖作者实际音乐，不得将测试文件提交或发布。

## 视觉与性能

截图保存于忽略提交的 `output/v11-qa/`。人工查看了桌面与手机启动页、首页、地图、人物、场景、生物、故事和创作理念的代表截图；修复手机关系图初始裁切、移动页脚标语隐藏和画廊大图裁切。

浏览器自动检查使用本机 Chrome/Chromium，并非所有浏览器或真实移动设备的完整兼容性认证。正式背景音乐尚无文件，其听感、循环接缝和最终响度未试听。原图分辨率沿用作者提供的作品集，不使用生成式放大。
